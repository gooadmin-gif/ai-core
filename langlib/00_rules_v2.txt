【読み方ルール】
・「01_dict_v2.txt」は単語辞書です。書式は「ID=単語(品詞)」です。
・「chat2_input_v2.json」は、文の意味を、単語IDと数値だけで役割ごとに分けて書いたものです。原文は見せていません。
・IDを辞書で引くと単語になります。辞書にないIDが出てきたら、推測せず「辞書にないID」と伝えてください。

【chat2_input_v2.json の形式】
{
  "version": "0.2",
  "sentences": [
    {
      "line": 1,
      "clauses": [                       // 文を意味のまとまり（節）に分けたもの。順番どおり。
        {
          "subject_ids": [],             // 主語の単語ID（無ければ []）
          "intent_ids": [],              // 述語（何をする／どうである）の単語ID
          "object_ids": [],              // 述語がとる対象・場所・相手などの単語ID。語順どおり
          "negation_ids": [],            // 否定の意味を持つ単語ID（無ければ []）
          "time_ids": [],                // 時を表す単語ID（無ければ []）
          "modifiers": [                 // 上のどれにも入らない修飾語と、それがかかる先
            {"id": 0, "target_id": 0}    //   id=修飾する単語ID / target_id=かかる先の単語ID
          ]
        }
      ],
      "relations": [                     // 節と節のつながり（無ければ []）
        {"id": 0, "from_clause": 1, "to_clause": 2}   // id=つなぐ語のID / 節番号は1から
      ],
      "scores": {
        "emotion": 0.0,                  // 感情の強さ。0=淡々／1=極めて強い
        "positivity": 0.5,               // 0=否定的／0.5=中立／1=肯定的
        "urgency": 0.0,                  // 緊急度。0=急がない／1=非常に急ぐ
        "certainty": 0.0,                // 話し手の確信度。0=自信なし／1=断定
        "irony": 0.0,                    // 皮肉度。0=皮肉なし／1=強い皮肉
        "formality": 0.0,                // 丁寧さ・硬さ。0=くだけた／1=非常に丁寧
        "emphasis": 0.0                  // 強調の強さ。0=なし／1=非常に強い
      }
    }
  ]
}
※ 数値は全て 0.0〜1.0 の範囲です。
※ 「//」以降は説明です。実際のファイルには書かれていません。
※ 同じ欄の中のIDの並びは、元の語順を表します。

【書き方の例】（例のIDは辞書にありません。形だけの説明です）
意味：「彼女は、高すぎたので、その赤い車を買わなかった」の形
  節1: subject=[彼女] intent=[買う] object=[車] negation=[not] modifiers=[{赤い→車}]
  節2: subject=[それ] intent=[である] object=[高い] modifiers=[{too→高い}]
  relations: [{because, 節1, 節2}]
